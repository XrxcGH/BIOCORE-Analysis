# Award Alignment — which two awards each robot archetype should chase, and what it costs

**Purpose:** turn the verified award list and the archetype corpus into one decision. For each
cross-season design/strategy archetype, name exactly **one PRIMARY and one SECONDARY** award, justify
both from FIRST's published criteria, price the materials in student-hours against this team's real
capacity, and say who does the work in which week. Because FIRST allows **one judged award per team
per event**, a wishlist is not a strategy — a pairing is.

**Companion file:** [`award_alignment_matrix.yaml`](award_alignment_matrix.yaml) — the fit matrix, the
seven pairings, the per-award materials checklists, the ranked design nudges and the Jan–Mar 2027
calendar, machine-readable.

**Evidence labels used throughout**

| Label | Meaning |
|---|---|
| **[C]** CONFIRMED | Verified in a primary source in this corpus |
| **[H]** HISTORICAL-PATTERN | Observed in prior-season FRC manuals/results; not stated for BIOCORE |
| **[S]** SPECULATION | Inference — fit scores, hour estimates, odds lifts. Flagged as such. Do not act on it as fact |
| **UNVERIFIED** | Could not be checked |

## 1. The four facts every recommendation below is derived from

### 1.1 One judged award per team per event [C] `JM`

> "Do not award the same team more than 1 judged award at a single event."

Back-tested at **99.992%** compliance over 23,167 TBA award rows (`AP` §6.2). This is why the
deliverable is a *pair*, not a list: preparing five lanes does not multiply your odds, it splits one
pit conversation five ways.

### 1.2 Every machine award is worth identical District points [C] `REB` Table 11-1

> "10 points for FIRST Impact Award / 8 points each for Engineering Inspiration and Rookie All Star
> Awards / 5 points each for all other team judged awards"

Quality, Creativity, Industrial Design, Excellence in Engineering, Innovation in Control, Autonomous,
Imagery, Judges, Gracious Professionalism, Team Spirit, Team Sustainability, Rising All-Star — **all 5.**
There is therefore **no points reason** to prefer a hard award over an easy one. Choose on probability.

### 1.3 The archetype does not choose most awards [C] `WEB-M`/`WEB-T`

Only nine awards have published criteria that reference the *machine* or *in-match behavior*:
Autonomous, Creativity, Excellence in Engineering, Industrial Design, Innovation in Control, Quality,
Imagery, Judges, Gracious Professionalism. The rest (Engineering Inspiration, Rising All-Star, Team
Spirit, Team Sustainability, FIRST Impact, FIRST Leadership, Woodie Flowers Finalist, both animation
awards) are **team-level** — the same answer regardless of what you build. §2 extracts pairings from the
robot-coupled set; §6 runs the team-level set in parallel.

### 1.4 Accessibility, measured, not asserted [C] `AV` §7 / `AP` §4

% of winners drawn from the **bottom half** of qualification rank, 2022–2026, n = 23,167 award rows:

### 2.2 The scoring rubric — how a cell gets its number [S]

| Score | Meaning | Test |
|---:|---|---|
| **3** | The award's decisive published guideline sentence describes this archetype almost verbatim, and the evidence is a **byproduct** of building it | Can you quote one sentence from `WEB-M`/`WEB-T` that names what this robot does? |
| **2** | Strong fit; evidence exists but must be **deliberately produced** (a plot, a render, a log) | Is there a real artifact you would have to make on purpose? |
| **1** | Arguable; the team must **manufacture a story** to connect robot to criteria | Would a judge have to be led there? |
| **0** | No causal link, or a **hard eligibility gate** blocks it | e.g. Rookie All-Star: `JM` "team number 10,900 or higher" |

**Extraction rule.** PRIMARY = highest cell. SECONDARY = next highest. Ties break on §1.4
bottom-half share (higher wins), then on lower marginal student-hours. Columns marked **‡** are
team-level (§1.3) and are **excluded from extraction** — they run in parallel (§6) and are not blocked
by the one-award rule in the way two prepared robot lanes are. The **Judges Award** is additionally
excluded from SECONDARY unless it scores 3, because it is structurally unpitchable (`AP` §3.8): you
cannot prepare for "a positive attribute not addressed in the criteria for other awards."

### 2.6 The causal justification, award by award — this is the audit

Each row quotes the sentence from FIRST's published criteria that makes the link causal rather than
decorative. Verbatim text is `[C]` `WEB-M`/`WEB-T` via `AV` §2.2/§2.3; the *link* is `[S]`.

**I1 → Quality Award (PRIMARY).** Criteria: *"Celebrates machine robustness in concept and
fabrication"*; the deciding guideline is *"A team must be able to describe **their quality plan** i.e.
how their design ensures robustness throughout the entire competition."* The simplified I1 variant
**is** a quality plan expressed as hardware: one mechanism chain of ≤3, one setpoint, one distance,
one failure mode, one spare. `AC` R2 records the failure profile as *graceful* — you miss a burst,
you do not die. That is literally the property the guideline asks judges to test, and every artifact
is a byproduct of building it (§3.1).

**I1 → Creativity Award (SECONDARY).** Criteria: *"a creative robotic component, concept, or attribute
that enhances strategy of play that was **intentionally designed and not discovered**"*, plus *"since
creativity may involve risk of failure, the team should be able to **describe how they mitigated that
risk**."* The creative act in I1 is not the mechanism, it is the **scope decision** — surveying one
firing position and building the whole machine around one distance is a strategy-enhancing concept
that was designed, not discovered. The risk (you cannot score from anywhere else) has a documented
mitigation: the shot chart and the field-position rehearsal. Opportunistic — it only works if a
student can say *why* the fixed position was chosen, **with a number**.

**I2 → Creativity Award (PRIMARY) / Industrial Design Award (SECONDARY). ⚠ REJECT ROW.**
Creativity is the only FRC award whose criteria pay for ambition, and Industrial Design's *"**The
entire machine**, and not just a single component"* is the do-everything pitch verbatim. Both links
are real. **Neither is reachable**: `AC` records **0/5** small-team successes for I2 across five
seasons, and `CM` caps this team at **2.00 novel mechanisms** against I2's median of 4. This row
exists so the kickoff meeting has something explicit to reject (`AC` §9, I2 slot prompt). See §5.1.

**I3 → Judges Award (PRIMARY).** Criteria: *"the judging panel may decide a team's unique efforts,
performance, or dynamics merit recognition"*; deciding guideline: *"The team exemplifies a positive
attribute or feature that is **not addressed in the criteria for other awards**."* A defense
specialist has, by construction, **no machine award to win** — every AUT/EIE/IND/IIC cell in its row
is 0. That is not a weakness in the Judges lane, it is the **eligibility condition** for it. Judges is
also the most accessible award in FRC: 787 distinct winners, 49.6% from the bottom half, only 31.5%
of wins to repeat winners.

**I3 → Gracious Professionalism Award (SECONDARY).** Criteria: *"outstanding demonstration of FIRST
Core Values such as continuous Gracious Professionalism, sportsmanship, and working together both **on
and off the playing field**."* Defense is the single place on an FRC field where sportsmanship is
directly observable, and Match Observer reports reach the judging panel. A defense robot that plays
hard, draws no fouls and helps opponents recover is generating GP evidence in every match. The
inverse is the risk: `AC` records I3's failure mode as *"foul risk, not breakage"* — a dirty defense
robot converts this lane into a negative.

**I4 → Excellence in Engineering Award (PRIMARY).** Criteria: *"the team whose machine incorporates an
engineering solution designed to have components work together seamlessly"*; deciding guideline:
*"**Teams do not have to design a robot that solves all game challenges.**"* An endgame specialist is
a robot that deliberately solves one challenge, in one 15–30 second window, with one integrated
mechanism — the exact object that sentence legitimizes. `AC` I4's lesson ("find the RP threshold, buy
the cheapest tier that clears it") **is** a documented engineering trade study, which is what the award
judges. Caveat: 62.5% of EIE winners were still qual top-8.

**I4 → Creativity Award (SECONDARY).** The risk-mitigation clause is written for single-shot
mechanisms: *"since creativity may involve risk of failure, the team should be able to describe how
they mitigated that risk."* `AC` records I4's reliability profile as *"single-shot. Miss the hook = 0.
No partial credit."* The mitigation story — N attempts, M successes, a backup hook geometry, a hard
stop — is simultaneously the Creativity answer and the Quality answer, so the artifact is
double-counted (§3.4).

**I5 → Innovation in Control Award (PRIMARY).** Criteria: *"an innovative control system or
application of control components – electrical, mechanical or software – to provide unique machine
functions"*; deciding guideline: *"The innovation is practical; it addresses the game's challenge and
is **reliable under the stress of competition**."* A scoped AUTO specialist is 100% control system and
0% mechanism (`AC` median mechanism count: **0**), and the evidence is a telemetry log you already
record. IIC does **not** require you to out-score the field — only to be reliable and explainable.

**I5 → Autonomous Award (SECONDARY, opportunistic only).** Criteria: *"consistent, reliable,
high-performance robot operation during autonomous ... actions"*; deciding guideline: *"**Consistent
and reliable operation is weighted more heavily than the ability to score maximum points**."* Read
alone that is a perfect fit. Read against the data it is not: **80.4% of Autonomous winners were qual
top-8, only 4.9% came from the bottom half, and the median winner sits at the 9.0th rank percentile**
— the most performance-coupled judged award in FRC. Take it only if your auto is genuinely among the
best three at the event. That is why it is SECONDARY and IIC is PRIMARY.

**I6 → Gracious Professionalism Award (PRIMARY).** A support robot's entire design thesis is *"make my
alliance partners better"* — `AC` R3 measures the effect at **+20–40% partner throughput**. The GP
criteria sentence is *"working together both on and off the playing field"*, and the deciding
guideline is the pre-season collaboration bullet: *"**If the team worked with another FIRST Robotics
Competition team pre-season** — they can describe ... How the collaboration was conducted ... The
financial impacts of working together vs working independently."* That bullet is a **checklist you can
deliberately satisfy before January** (§4 nudge N13). GP is 41.2% bottom-half.

**I6 → Creativity Award (SECONDARY).** *"a creative robotic component, concept, or **attribute that
enhances strategy of play**"* — a robot that scores zero points itself and raises alliance throughput
20–40% is the purest possible instance of a strategy-enhancing attribute that was intentionally
designed. `AC` scores I6 at **5/5 = 100%** small-team success, so the robot will exist and work; the
only open question is whether the team can articulate the strategy. Creativity is the most open
machine award (706 distinct winners).

**I7 → Quality Award (PRIMARY).** *"Celebrates machine robustness in concept and fabrication"* +
*"describe their quality plan."* "It never failed" **is** the Quality Award thesis. `AC` records I7's
reliability profile as *"two independent simple systems; degrades gracefully"* and its small-team
success as **5/5 = 100%**. The distinguishing evidence is a **count**: matches played, failures, mean
time to repair. No other archetype produces that number as cheaply.

**I7 → Excellence in Engineering Award (SECONDARY).** *"**Teams do not have to design a robot that
solves all game challenges.**"* This is the only sentence in FIRST's published criteria that
legitimizes a deliberately minimal robot, and it converts what reads as under-ambition into a stated
engineering position. The pitch is a trade study: here is what we did **not** build, here is the
capacity number that made that correct (`CM` **novel_mechanisms_max = 2.00**), here is the reliability
we bought with the hours we saved.

### 2.7 Systemcore adjustment [H]/[S]

The 2027 season replaces the roboRIO with **Systemcore**, and WPILib 2027 is Systemcore-only and
*"incompatible with the Rio"* (`CM` §3.2, `PF` §6.3). Two consequences for this file:

| Lane | Effect | Mitigation |
|---|---|---|
| **I5 → Innovation in Control / Autonomous** | The highest-risk pairing in the file. `AC` §9.4 applies a **+0.5 to +1.0 programming-difficulty penalty** to every rating until library maturity is known; I5 is already difficulty 5 | Scope the auto to **1–2 elements** (`AC`: 5/5 small-team success when scoped, 0/3 at full scope). Do not promise a multi-element auto in a January pit interview |
| **All telemetry-dependent plots** (§4 N03) | The `DataLogManager`-equivalent API on Systemcore is **UNVERIFIED**. Budget **+2 h** to locate it, keep a CSV fallback | Establish the logging habit on the **2026** robot in Oct–Dec 2026, before the platform changes |

`CM` also prices the Systemcore port at **+30 veq-h vs a normal year** inside a 134.8 h programming
line at **79% pre-committed utilisation**. Every hour §3 asks of a programmer competes with that.

### 2.8 What this matrix does *not* claim

- It does not predict a win. §1.4's figures are **correlational** (`AV` Known Limitations): Rising
  All-Star's 69.1% bottom-half share reflects who is *eligible*, not what helps.
- There is **no numeric judging rubric** to align to. `JM`: *"The guidelines for all awards should not
  be viewed as strict criteria that should be met to win any award."* The only scored rubric FIRST
  publishes belongs to the Digital Animation Award (WPI). Any system claiming to score you against an
  FRC judging rubric is inventing it (`AV` §8).
- Fit scores are `[S]`. The **quotes** are `[C]`; the mapping from quote to archetype is judgement,
  which is why §2.2 publishes the rubric and §2.6 publishes the reasoning line by line.

### 2.9 Where this file disagrees with `AC` §7.2, and why

|---|---|---|---|

| **I6** feeder / support | Industrial Design · Team Spirit | **Gracious Professionalism · Creativity** | Team Spirit is archetype-independent (§1.3) — a support robot does not *cause* it. | **I1** volume scorer | Quality · Industrial Design | **Quality · Creativity** | Industrial Design is 11.9% bottom-half and demands whole-machine finish this team has no hours for (§3.3); Creativity is 28.1% and rewards the scope decision I1 already made |

## 3. Materials plan — one checklist per award

Eight awards appear across the fourteen pairing slots. Each gets a checklist below covering the eight
required deliverable types: **pit display · technical binder · one-page handout · CAD renders ·
test-data plots · video · 5-minute pitch outline · judge-question prep.**

Hours are **nominal student-hours** `[S]`, i.e. what a real student actually spends — *not* veq-h. §3.10
converts. Items marked **(free)** are byproducts of §4's habits and cost ~0 marginal hours if those
habits exist; they cost the listed hours as **reconstruction** if they do not.

### 3.0 Two rules that shape every checklist [C] `JM`

> "Judges are encouraged to take team provided materials and review them as time allows. ... **There are
> no restrictions on page limits** of documents but please be aware that **judges are not expected to
> review every piece of material** handed to them during the event and teams are encouraged to include
> the most relevant information **in their interview**."

**The interview is the channel; paper is a leave-behind.** One page a judge reads beats a 40-page
binder they do not. Do **not** apply `JM`'s 2" binder guidance — that appears in Chapter 5 and governs
the scheduled **FIRST Impact Award** interview, not pit machine-award judging (`AP` §5.2). Applying FIA
binder norms to a pit interview wastes 30+ student-hours.

> "Judges should not touch a team's robot unless directly invited by the team."

**Every checklist below contains the sentence "would you like to try it?"** as a rehearsed line. A
cutaway, a removable panel or a bench demo produces nothing unless a student says it out loud. This is
why a *spare* mechanism on the pit table outperforms the same mechanism bolted to the robot.

### 3.10 The 5-minute pitch outline (one template, four swappable middles)

`WB`: *"Judges should make a concerted effort to conduct the interview while the robot and spokespersons
are in the team's pit."* Assume 5–8 minutes, standing, noisy, interrupted.

| Time | Beat | Who | Content |
|---|---|---|---|
| 0:00–0:30 | **The one sentence** | Student A | "We are a 15-student team. We built one thing and we built it to work every match. Here it is." Name the archetype, not the game |
| 0:30–1:30 | **The decision** | Student B | The trade: what we did **not** build and the number that decided it. Hand over the one-pager here, not at the end |
| 1:30–3:00 | **The lane-specific middle** | Student C | QUA: the quality plan + the reliability count · CRE: origin story + risk mitigation · EIE: the trade study · IIC: the plot on the laptop · GP: the collaboration table |
| 3:00–3:30 | **The invitation** | Student C | ***"Would you like to try it?"*** — hand them the spare or the bench rig. `JM` forbids them touching the robot uninvited |
| 3:30–4:30 | **Their questions** | whoever knows | §3.11. Any student may answer. "I don't know, but *she* does" is a correct answer |
| 4:30–5:00 | **The close** | Student A | One forward-looking sentence: what we would change, and the date we found that out |

**Three students minimum, all of whom can give all beats.** `AP` §1.3: day 1 shortlists you, day 2 wins
it — the students who are in the pit on day 2 are the ones who must be rehearsed, and on a 15-student
team those are usually not the same people as day 1.

### 4.1 The top five, in one paragraph each

**N01 — dated photos.** `AP` §5.1 calls this "the single highest-leverage habit," and §3.9 shows why:
six of eleven shared artifacts are free byproducts if you do it and expensive reconstructions if you do
not. **This decision must be made in week 1 of build, not week 6.** Cost: creating one shared album and
saying it out loud at the first meeting.

**N02 — keep the failed prototype.** The Creativity guideline asks how you *mitigated risk*; the
Excellence in Engineering guideline asks about *the detailed process used to develop the design*. A
physical failed part on the pit table answers both in three seconds, and it is the only artifact in this
file that costs a quarter of an hour and can never be reconstructed later.

**N03 — log everything.** You already collect setpoints, currents, match timings and sensor values; the
only decision is whether they survive the match. One log-enable call converts the Innovation in Control
lane from "we would need to build something" to "open the laptop." It also halves debug time, which is
the reason to do it even if you never talk to a judge. **Systemcore caveat:** the 2027 logging API is
UNVERIFIED (§2.7); establish the habit on the 2026 robot in the autumn, budget 2 h to re-find it, keep
a CSV fallback.

**N04 — write the decision record as you go.** Fifteen minutes at the end of each build week, in a
shared doc: *date · decision · alternative rejected · reason*. Ten weeks = 2.5 h. Reconstructing the
same document in week 9 costs 12 h and produces a worse, half-invented artifact — which is exactly the
anti-pattern in §5.2. This single file is the Excellence in Engineering pitch, the Creativity origin
story, and the answer to Q4/Q9/Q14.

**N07 — number your reps.** A sheet of paper on the wall with two columns. "We have attempted 214
climbs and succeeded on 197" is the most persuasive sentence available to a small team in a pit
interview, it costs one hour to set up, and it is the same number that tells you whether the mechanism
is ready. `PF` weights drive practice at **90 — the highest factor in the measured corpus** — and this
nudge is how you find out whether the practice is working.

### 4.2 What is deliberately *not* on this list

- **A large technical binder.** §3.0: judges are not expected to read it, and FIA binder norms do not
  apply to pit judging.
- **A robot video for its own sake.** No pit-judged award requires one; the only award with a video
  field is FIRST Impact, which this team is not chasing (§2.4). N15 is ranked last for that reason.
- **A separate award-materials sub-team.** `CM` §4.1 shows 15 students already cover 14+ functions with
  mandatory role sharing. The awards lead is **slot #9** and shares with media; every nudge above is

## 5. Anti-patterns

### 5.1 Chasing an award the robot does not support

The named failure: building for **I2, the do-everything robot**, because Creativity and Industrial
Design have the most attractive criteria. `AC` records **0/5** small-team successes for I2 across five
seasons and states the mechanism: *"cost is multiplicative, not additive: each extra mechanism
multiplies integration debt, and integration debt is paid in the weeks that would have been drive
practice."* `CM` sets `novel_mechanisms_max = 2.00`. **The award does not move that number.**

Two more instances of the same error:

- **Chasing the Autonomous Award with a one-element auto.** 80.4% of winners were qual top-8; the
  median winner sits at the 9.0th rank percentile. §3.6 exists precisely so this costs 6 marginal hours
  instead of 40, and only after you have seen your auto beside the field.
- **Chasing the FIRST Impact Award without a three-year record.** 77.7% of wins go to repeat winners;
  only 446 distinct teams in five seasons. It is worth 10 District points and it is the single most
  concentrated award in FRC. The FIA judging guidelines do tell judges to *"Consider utilization of team
  resources, especially when comparing large teams vs small teams"* — real, and not enough to close a
  three-year gap (`AV` §7.2). **The 40+ hours an FIA submission costs buy more elsewhere.**

**Test before committing:** can you name the sentence in `WEB-M`/`WEB-T` that describes your robot? If
you cannot, the fit is 1, not 3, and §2.3 already told you so.

### 5.2 Retrofitting a story

Writing the sustainability narrative in week 6. Reconstructing the design-decision record the night
before the event. Photographing a finished robot and calling it process documentation.

Retrofitting is detectable and expensive. It is **expensive** because §3.9's cold-vs-warm columns price
it: 89 hours cold, 21 hours warm — a **4.2×** penalty for starting late. It is **detectable** because
every retrofitted artifact lacks the one thing FIRST's criteria repeatedly ask for: **dates**. The
Engineering Inspiration guideline asks for *"performance indicators that provide measurable success"*;
the Creativity guideline distinguishes *"intentionally designed"* from *"discovered"*; the Gracious
Professionalism guideline asks specifically about **pre-season** collaboration. All three are date
questions.

**The rule:** if an artifact cannot carry a truthful date, do not make it. Make a different one.

### 5.3 Spreading thin

Five prepared lanes do not multiply your odds by five. `JM`: *"Do not award the same team more than 1
judged award at a single event."* Five lanes means one pit conversation split five ways, five one-pagers
nobody reads, and — the real cost — **five sets of rehearsals that never reach fluency**. `AP` §4 puts
it as: two prepared lanes plus the free Judges option is the efficient frontier; a third mostly buys
overlap.

Arithmetic: §3 shows a prepared lane costs 28–45 h cold. The team has **47–90 nominal student-hours**
for award materials in-season (§6.2). Two lanes fit. Three do not, and the third displaces the drive
practice `PF` weights at 90.

### 5.4 Four smaller ones

| Anti-pattern | Cost | Fix |
|---|---|---|
| **Binder inflation** — applying the FIA 2" binder guidance to pit judging | 30+ student-hours (`AP` §5.2) | ≤10 sheets, one bound unit, plus a one-pager you actually hand over |
| **The untouched demo** — building a cutaway nobody invites judges to use | 8–12 h wasted | Put *"would you like to try it?"* in the rehearsed script (§3.10, 3:00 beat) |
| **Overclaiming** — promising a capability the robot does not show on the field | Credibility, and Match Observers verify (`AP` §5.4) | Claim the reliability number you measured, not the design intent |
| **Printing sponsor suffixes early** — a sponsor moved on at least one award in **every** season 2022→2026 (`AV` §1.2) | Reprinting, or a wrong handout | Print handouts with the unsponsored short name until the 2027 award pages re-issue (Oct–Dec 2026) |

## 7. The district-points argument: awards and pickability are the same currency as scoring

`REB` §11.1 / Table 11-1, verbatim [C]:

| Category | Points |
|---|---|
| **Qualification Round Performance** | "Normal distribution of points from **22 to 4** across the highest ranked team to the lowest based on an equation" |
| **ALLIANCE CAPTAINS** | "Equal to **17 minus the ALLIANCE CAPTAIN number** (e.g. 14 points for ALLIANCE #3 Captain)" |
| **Draft Order Acceptance** | "Equal to **17 minus the Draft Order Acceptance Number** (e.g. **12 points for the team that accepts the fifth draft position**)" |
| **Playoff Advancement** | DE points: 4th place **7**, 3rd place **13**, Finalist **20**, Winner **20** + 5 per Finals win |
| **Team Judged Awards** | "**10** points for FIRST Impact Award / **8** points each for Engineering Inspiration and Rookie All Star Awards / **5** points each for all other team judged awards" |

**"Points earned at District Championships are multiplied by 3."**

### 7.1 What 5 points is actually worth

Sample 40-team qualification distribution, `REB` Table 11-3: rank 1 = **22**, rank 3 = **20**,
rank 19–20 = **13**, rank 21 = **12**, rank 37–38 = **6**, rank 39 = **5**, rank 40 = **4**.

The **entire** qualification spread — best robot at the event to worst — is **18 points**.

| Comparison | Points |
|---|---:|
| One "other team judged award" (Quality, Creativity, Judges, GP, …) | **5** |
| Climbing from rank 30 → rank 20 at a 40-team event | ≈ **4** |
| Climbing from rank 40 → rank 21 — i.e. beating **half the field** | **8** |
| Being drafted at slot 5 | **12** |
| Being drafted at slot 5 **+ one judged award** | **17** |
| Finishing **1st in qualification** | 22 |

**Read the third and fourth rows together.** A single 5-point judged award is worth more than climbing
ten qualification places. **Being picked fifth is worth more than out-qualifying 19 of 39 opponents.**
For a team whose measured ceiling is 2 novel mechanisms and 9 hours of pre-event drive practice
(`CM` §3.4), those are not comparable investments.

### 7.2 Two seasons, four scenarios, same robot

Two District events, 40 teams each. The robot is identical in all four; only the *award and pickability*
work differs `[S]`.

| Scenario | Qual (rank) | Alliance | Playoff | Award | **Per event** | **2 events** |
|---|---:|---:|---:|---:|---:|---:|
| **A** Field only, unpicked, no award — qual rank 28 | 9 | 0 | 0 | 0 | **9** | **18** |
| **B** Same robot, picked 12th overall (§4 makes you legible) | 9 | 5 | 0 | 0 | **14** | **28** |
| **C** B + one 5-point judged award | 9 | 5 | 0 | 5 | **19** | **38** |
| **D** Picked **5th** (reliable, fast to repair, useful) + award + alliance loses in the semis (4th place) | 9 | **12** | **7** | 5 | **33** | **66** |

**Scenario D is 3.7× Scenario A on the same robot.** Every delta between A and D is bought by things in
§4: legibility, reliability, a rehearsed pit conversation, a number you can quote to a scout, and 21
warm hours of materials.

Add the DCMP multiplier: one 5-point award at a District Championship is **15 points** — nearly the
entire qualification spread of a 40-team event, earned in a 12-minute conversation.

### 7.3 Why "pickable" and "award-winning" are the same investment [C] `REB` §11.1.2

> "To be invited to join an ALLIANCE, a team's peers have decided that the team has attributes that are
> desirable. ... These points also have the potential to recognize teams employing a **unique strategy**
> with their ROBOT. Teams with **unique or divergent ROBOT capabilities that complement the strengths of
> other ALLIANCE members** may be selected to fill a strategic niche."

FIRST wrote the district-points system to reward the same property the judging system rewards: **a
robot whose role is legible and whose reliability is demonstrable.** `AC`'s base-rate anchor makes it
concrete — **78% of 2026 winning alliances carried a below-median-OPR robot**, and at half of 2026
events a robot in the bottom decile of OPR was still selected. Being picked is not gated on scoring.
It is gated on being legible, reliable and useful — which is *exactly* what the Quality, Creativity,
Excellence in Engineering and Gracious Professionalism criteria measure.

**The conclusion:** §4's nudges are not award overhead. The reliability tally (N07), the failure log
(N06), the telemetry (N03) and the rehearsed 90-second explanation (N11) are simultaneously your
judging evidence and your **scouting pitch** to alliance captains. One artifact set, two point streams,
denominated in the same currency.

### 7.4 The honest caveats

- **Regional-model teams do not earn District points at all.** Championship advancement runs through
  the points-based Regional Pool from a team's first two Regionals (`AV` §5.2). Sections 7.1–7.3 apply
  to District teams; for Regional teams the same argument holds qualitatively (awards and pickability
  both matter) but the arithmetic above does not.
- **Table 11-3 is a *sample* 40-team distribution.** `REB`: "The system will automatically generate the
  appropriate points for each team based on their rank and the number of teams at the event." Numbers
  shift with event size.
- **Scenarios B–D are `[S]`.** Nothing in this corpus measures how much a rehearsed pit pitch raises
  draft position. The *structure* of the argument is `[C]` (all point values are quoted verbatim); the
  claim that §4 moves a team from A to D is a judgement.
- **These are 2026 REBUILT values.** `REB` §11 has been stable in structure across 2022–2026, but
  re-verify Table 11-1 in the BIOCORE manual on 2027-01-09 — `RULE-CHURN-WATCHLIST.md` tracks §11.

## 8. Validation / dry run

### 8.1 The extraction is reproducible from the matrix

`award_alignment_matrix.yaml` carries the fit matrix and the extraction rule as data. This
re-derives §2.5 from §2.3 and asserts equality:

```bash
# Run from the repository root.
cd reference/awards
python - <<'PY'
import yaml
d = yaml.safe_load(open("award_alignment_matrix.yaml", encoding="utf-8"))
acc  = {a["code"]: a["pct_bottom_half_winners"] for a in d["awards_robot_coupled"]}
ok = True
for row in d["fit_matrix"]:
    cells = row["scores"]
    # extraction rule: exclude JUD from SECONDARY unless it scores 3
    rank = sorted(cells.items(), key=lambda kv: (-kv[1], -acc[kv[0]]))
    primary = rank[0][0]
    rest = [c for c, s in rank[1:] if not (c == "JUD" and s < 3)]
    secondary = rest[0]
    pr = next(p for p in d["pairings"] if p["id"] == row["id"])
    got = (pr["primary"]["code"], pr["secondary"]["code"])
    exp = (primary, secondary)
    flag = "OK " if got == exp else "MISMATCH"
    if got != exp: ok = False

print("\nALL PAIRINGS REPRODUCE" if ok else "\n!! MATRIX AND PAIRINGS DISAGREE")
PY
```
