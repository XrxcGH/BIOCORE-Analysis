# `manuals/`: FIRST source documents

This directory holds the FIRST documents the analysis is built from: the game manuals, Q&A exports, Team Updates, field drawings and CAD under `archive/`, and the kickoff-day ingest of the new manual under `2026-27_BIOCORE/`. None of it is in the repository, because the documents are FIRST's copyrighted material; the full set is also about 2.2 GB, and three of the files exceed GitHub's 100 MB limit. From the repository root, `bash tools/rebuild-corpus.sh --fetch` downloads the source PDFs into this directory and `reference/awards/pdfs/`, and `bash tools/rebuild-corpus.sh` then regenerates the text extractions the tools read and names any PDF that is still missing. The only other tracked file under this directory is `2026-27_BIOCORE/README.md`.
