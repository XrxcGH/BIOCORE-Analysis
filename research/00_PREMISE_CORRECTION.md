## Specific corrections to seeded assumptions

1. **"Kickoff is September 12"** — that is the **FTC BIOBUZZ** kickoff, i.e. the *sibling* project.
   **FRC BIOCORE kickoff is January 9, 2027.** There is no September 2026 FRC game reveal.
   Source: [FIRST — BIOCORE Game & Season](https://www.firstinspires.org/programs/frc/game-and-season)

2. **"Pollen is the BIOCORE scoring element"** — FALSE. Pollen is the **FTC BIOBUZZ** scoring element.
   Source: [Game Preview 2027: StarterBots, Skill Builders, Field Elements and More!](https://community.firstinspires.org/game-preview-field-elements) — this post is an **FTC** post about BIOBUZZ, despite the "2027" in its title.

3. **"StarterBots and Skill Builders are part of BIOCORE"** — FALSE. Both are **FTC BIOBUZZ** programs.

That is an inference, **not** a confirmed fact. Track the AndyMark product page and the FIRST CANOPY page for the reveal of its name and specs.

### The September dates, side by side — the single most confusable thing in this project

| Date | Program | What it is | Does a game get revealed? |
|---|---|---|---|
| **Sept 1, 2026** | Cross-program | *FIRST* Scholarship Program opens | No |
| **Sept 12, 2026** | **FTC** | **BIOBUZZ kickoff — game revealed, season begins** | **Yes — but FTC, not FRC** |
| **Sept 24, 2026, 12:00 ET** | **FRC** | Kit & Kickoff Registration opens **+** Event Registration Round 1 preferencing opens | **No** |
| **Nov 12, 2026** | FRC | Pre-Kickoff Virtual Kit Release | No — but largest pre-kickoff info drop |
| **Jan 9, 2027, 12:00 ET** | **FRC** | **BIOCORE kickoff — game revealed, manual released** | **Yes** |

**There is no FRC event of any kind on September 12, 2026.** The FRC date near it is **September 24**, and it is a registration deadline, not game content. Miss Sept 24 and you lose Round 1 event preference — which for a Regional team is the difference between your first-choice event and whatever is left.

Meanwhile **September 12, 2026 is a real and near deadline, for the FTC BIOBUZZ project next door** (`../BIOBUZZ Analysis`).
